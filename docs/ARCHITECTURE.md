# المعمارية

## التدفق

1. المستخدم يكتب طلبًا عربيًا في الواجهة.
2. `request_parser` يستخرج العملية، نوع العقار، المناطق، المساحة، الميزانية، الدخل، والميزات.
3. `alforaij` connector يقرأ بيانات الفريج المحلية.
4. `matching` يحسب درجة المطابقة.
5. `valuation` يجلب عروضًا مشابهة ويصنف السعر.
6. `deduplication` يدمج التكرارات الواضحة.
7. `report_generator` يعيد تقرير JSON عربي للواجهة.

## الفصل

- `frontend/`: واجهة HTML/CSS/JS.
- `backend/services/`: منطق الفهم والمطابقة والتقييم.
- `backend/connectors/`: مصادر البيانات الحالية والمستقبلية.
- `data/`: إعدادات وقواعد ونسخة seed.
- `supabase/`: مخطط قاعدة البيانات المستقبلية.
- `mcp_server/`: نقطة ربط مستقبلية مع أدوات خارجية.
