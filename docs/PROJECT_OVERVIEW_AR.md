## 1) ما هي المنصة؟

**منصة الفريج للفرص والتقييم العقاري** — منصة كويتية تجمع إعلانات العقار من الفريج والمصادر الخارجية في مكان واحد، وتقيّم كل عقار بالصفقات المسجلة الرسمية (الحسبة) ومؤشرات السوق، وتصنّف الفرص الاستثمارية، وتُصدّر تقارير موثقة قابلة للمشاركة عبر واتساب.

**الوعد المركزي:** «مجاني وأدق» — بيانات مجانية واحترافية بدل الاشتراكات المدفوعة عند المنافسين، مع توثيق المصدر لكل رقم.

---

## 2) ما بُني فعليًا (حالة الإنجاز)

### البيانات والمصادر
- **حصاد خارجي**: 9 مصادر حية (4Sale، OpenSooq، Mourjan، Q8Aqar وغيرها) + إعلانات الفريج المحلية، ~8 أنواع عقار (بيت، شقة، أرض، عمارة، عقارات…).
- **الصفقات الرسمية**: جدول `official_transactions` للصفقات المسجلة (السعر الفعلي لا المطلوب) + فحص دوري للمصادر الرسمية المرجعية (`/api/official-reference-sources`).
- **مؤشرات الأسعار**: جدول `price_trends` (متوسطات شهرية لكل منطقة/نوع) تُعرض حيًا من القاعدة عبر REST العام.
- **إحداثيات المناطق**: `data/kuwait_areas.json` — 139 نقطة وسط مرجعية بأسس موثقة (`source` لكل منطقة)، شملت تصحيحًا جوهريًا لمواقع المطلاع وصباح الأحمد والبحرية والوفرة (كانت خاطئة بعشرات الكيلومترات).

### التحليل والتقييم
- **تقييم بالصفقات**: «الحسبة» تعتمد الصفقات الرسمية أولًا ثم الإعلانات المشابهة، بسياسة صارمة (لا رقم بلا مصدر، لا خلط بين المساحة والارتداد).
- **درجة الفرصة**: تصنيف كل إعلان إلى فرصة / مناسبة / تحتاج مراجعة بسلم موحد يظهر في اللوحة وعلى الخريطة.
- **لوحة تحليلات السوق**: جداول المحافظات، فجوة السعر (السعر المطلوب مقابل السوق)، عائد الإيجار، مؤشرات الطلب المحفوظة.
- **محاكي الصفقات الاستثمارية**: ROI وفترة الاسترداد قبل اتخاذ القرار.

### الواجهة
- **صفحة البحث والتقييم** مع وضع مبسّط للباحث العادي (بطاقات أكبر، فلترة بالنقر، زر اتصال مباشر).
- **خريطة تفاعلية Leaflet**: دوائر المناطق الملونة بفجوة السعر/العائد + **نقاط كل إعلان** بدرجة فرصته + فلترة بنقر المصدر/النوع (تُحمَّل مكتبة Leaflet كسولًا من CDN).
- **سجل سعر العقار**: خط زمني لسعر كل إعلان عند كل ظهور (جدول `listing_price_observations`) يظهر في بطاقة التحليل.
- **بطاقات تقييم قابلة للمشاركة**: زر واتساب لكل تقييم بسعره وأدلته + عداد مشاركات (`share_counts`) يعمل على الموقع الثابت بلا خادم.
- **صفحة «لماذا مجاني وأدق»**: مقارنة شفافة بأسعار المنافسين الموثقة ومصادرها + زر مشاركة واتساب للمقارنة الموجزة.
- **نظام حسابات مجاني**: تسجيل بالهاتف (OTP عبر واتساب)، بحث محفوظ، وتنبيهات واتساب مطابقة عند نزول فرصة جديدة.

### التشغيل الآلي والنشر
- **وكيل التحديث اليومي** (6:00 صباحًا): يحصد المصادر، يسجّل سجل الأسعار، يكشف الفرص، يرسل تنبيهات الوكلاء عبر **قوالب واتساب UTILITY معتمدة** (تعمل خارج نافذة الـ24 ساعة).
- **CI/CD**: 6 سير عمل GitHub Actions (pytest، أداء، جوال، 3 نشرات: GitHub Pages + Cloudflare Pages + لوحة) — والنشر يولّد اللقطة الثابتة (`static-data/`) آليًا.
- **البنية**: باك إند Python بالمعيار القياسي (بلا إطار ثقيل)، واجهة JS أصيلة بلا مكتبات، Supabase (23 ترحيلًا: RLS عام للقراءة).

### الجودة
- **439 اختبار pytest** + فحص sprint 33/33 + فحص جوال (390px: تجاوز، أهداف لمس ≥44px، صفر أخطاء كونسول) + فحص أداء + فحوص متصفح حقيقية (Chromium) لكل ميزة.

## 3) ما ينقص (مرتبًا بالأثر)

| الأولوية | الفجوة | لماذا هي الأهم |
|---|---|---|
| 1 | **تغطية كاملة للصفقات المسجلة (الحسبة)** | الفارق بين «منصة إعلانات» و«مرجع السوق» — السعر الفعلي لا المطلوب |
| 2 | **نموذج تقييم آلي (AVM) باختبار رجعي منشور** | يرفع الدقة من «تقدير» إلى «سلطة سعرية»: ننشر «خطأ نموذجنا في توقع صفقات الشهر الماضي: X%» |
| 3 | **مؤشر طلب حي منشور** | البحث المحفوظ والتنبيهات أصل بيانات طلب لا يملكه أحد غيرنا — تحويلها لمؤشر يظهر في التحليلات |
| 4 | **طبقة الثقة** | التحقق من أرقام الهواتف (مرتبط بالحسابات)، ترخيص الوسطاء (سجل PAHW)، زر «أبلغ عن إعلان مضلل» — الثقة تُسوَّق بها «أدق» |
| 5 | **تحقيق الدخل** | اشتراك للمحترفين (تنبيهات لحظية + تقارير بيضاء الشعار)، B2B API للبنوك والمثمّنين، عمولة إغلاق صفقات |
| 6 | **إدارة المحافظ** | المستخدم يسجّل عقاراته ويتابع قيمتها شهريًا — طُبع الجدول (`portfolios`) وبقي تلميع الواجهة والربط بالسجل الزمني |
| 7 | **توسع الدولة** | التصميم جاهز (بُعد `country_id`/عملة/وحدات) والمصادر موثقة للسعودية والإمارات — التنفيذ بعد إتقان الكويت |
| 8 | **تحسين كشف التكرار** | دمج الإعلانات شبه المتطابقة بحذر (منطقة+نوع+سعر+تطبيع العنوان) مع بوابة دقة تمنع دمج الوحدات المتشابهة شرعيًا |
| 9 | **تطبيق الجوال (PWA)** | إشعارات فورية + فتح مباشر للتنبيهات — أقصر طريق لرفع الارتباط اليومي |

## 4) الاقتراحات الاحترافية النهائية

1. **الخندق الحقيقي = الصفقة المسجلة، لا عدد المصادر.** كل ميزة جديدة يجب أن تُقاس بسؤال واحد: «هل تجعل سعرنا الموصى به أقرب إلى الصفقة الفعلية؟».
2. **انشر دقة نموذجك.** صفحة عامة تعرض اختبارًا رجعيًا شهريًا (خطأ التوقع مقابل الصفقات الفعلية). هذا وحده يفرّقك عن كل منافس كويتي ويبني «السلطة السعرية».
3. **حوّل البيانات المحفوظة إلى أصل.** البحث المحفوظ والتنبيهات = إشارات طلب حية. اعرض «مؤشر طلب» لكل منطقة/نوع — بيانات لا يملكها أحد غيرك.
4. **الثقة قبل الدخل.** التحقق من الهاتف والتراخيص وإبلاغ الإعلانات المضللة هي شرط أي اشتراك مدفوع لاحقًا — لا تقدّم الدفع قبلها.
5. **التوسع: دبي أولًا ثم السعودية** (المصادر موثقة في وثيقة التوسع) — فقط بعد إتقان الكويت، ودولة واحدة في كل مرة.
6. **الذكاء الاصطناعي مفتوح المصدر** (Meta/Nvidia) لتنظيف بيانات الإعلانات مجانًا وحماية الخصوصية — التفاصيل الكاملة في [خطة الذكاء الاصطناعي](OPEN_SOURCE_AI_PLAN_AR.md).
7. **لا تقلّل من قوة البساطة**: الوضع المبسّط والبحث الجغرافي والخريطة هم ما يجذب الباحث العادي — المحللون يأتون للعمق، والعامة للسهولة.

## 5) خارطة طريق واقعية

- **0–3 أشهر**: إكمال صفقات الحسبة + AVM بالاختبار الرجعي + مؤشر الطلب المنشور + طبقة الثقة.
- **3–6 أشهر**: تحقيق الدخل (اشتراك المحترفين + التقارير البيضاء + API) + محفظة المستخدم كاملة.
- **6–12 شهرًا**: بُعد الدولة في السكيما + دبي ثم السعودية + التحليل التنبؤي للأسعار (12–24 شهرًا قادمة).
