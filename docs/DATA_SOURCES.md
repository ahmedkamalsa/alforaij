# مصادر البيانات

## متصل فعليًا

`alforaij_board`: بيانات محلية مستخرجة من `site/index.html` في مشروع `alforaijboard`.

## غير متصل بعد

- منصة الفريج الأصلية مباشرة: الروابط محفوظة، لكن لا يوجد سحب مباشر الآن.
- مصادر خارجية كويتية: تحتاج موافقة على المصدر وطريقة الاستخدام.
- صفقات رسمية: تحتاج ملف أو API موثوق قبل استخدامها كدليل تقييم قوي.

## سياسة المساحة

لا يتم ملء مساحة العقار إلا من:

- حقل `space` الموجود في بيانات الفريج.
- عبارة صريحة مثل `المساحة 400 متر` أو `مساحتها 750 متر`.

ولا يتم استخدام:

- `ارتداد 40 متر`
- `واجهة 25 متر`
- `شارع عرض 30 متر`
