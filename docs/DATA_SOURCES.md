# مصادر البيانات

## متصل فعليًا

`alforaij_board`: بيانات محلية مستخرجة من `site/index.html` في مشروع `alforaijboard`.

## غير متصل بعد

- منصة الفريج الأصلية مباشرة: الروابط محفوظة، لكن لا يوجد سحب مباشر الآن.
- Sakan: رابط بحث خارجي جاهز.
- السوق المفتوح الكويت: رابط بحث خارجي جاهز.
- مرجان الكويت: رابط بحث خارجي جاهز.
- Q8Aqar: رابط بحث خارجي جاهز.
- صفقات رسمية: تحتاج ملف أو API موثوق قبل استخدامها كدليل تقييم قوي.

روابط البحث الخارجي لا تدخل في التقييم الحسابي الحالي، لأنها ليست بيانات منظمة داخل النظام. عند توفير API أو ملف CSV/JSON من أي مصدر، يتم تحويله إلى Connector فعلي ويظهر عدد نتائجه ومساهمته في التقييم.

## سياسة المساحة

لا يتم ملء مساحة العقار إلا من:

- حقل `space` الموجود في بيانات الفريج.
- عبارة صريحة مثل `المساحة 400 متر` أو `مساحتها 750 متر`.

ولا يتم استخدام:

- `ارتداد 40 متر`
- `واجهة 25 متر`
- `شارع عرض 30 متر`
