# القيود

- لا يضمن التطبيق توفر العقار فعليًا.
- لا يؤكد صحة كل إعلان.
- لا يقدم تقييمًا رسميًا معتمدًا.
- لا يستخدم مصادر خارجية الآن إلا كهيكل جاهز.
- لا يتجاوز تسجيل دخول أو CAPTCHA أو شروط استخدام.
- لا يرسل بيانات خاصة إلى خدمات خارجية.
- تقييم الاستثمار بالدخل يحتاج بيانات دخل وصفقات أكثر من المتاح حاليًا.
