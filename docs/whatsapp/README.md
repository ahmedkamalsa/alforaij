# إعداد واتساب: من حساب Meta حتى أول رسالة فعلية على الهاتف

هذا الدليل يُغلق الفجوة الأخيرة: الكود جاهز يرسل (قالب OTP للتحقق + قالب تنبيه
الفرصة) لكن التسليم الفعلي يتطلب حساب WhatsApp Business + قالبين معتمدين.
الأداة `scripts/whatsapp_setup.py` تنشئ القالبين **برمجيًا** وتفحص الجاهزية —
لا حاجة للتنقل في لوحة Meta يدويًا.

---

## 0) ما الذي يحتاجه النظام منك (مرة واحدة، في Meta)

| العنصر | من أين | ماذا تفعل به |
| --- | --- | --- |
| **حساب أعمال فيسبوك** | business.facebook.com | الشرط الأساسي لكل ما يلي |
| **تطبيق** | developers.facebook.com → إنشاء تطبيق (Business type) | تُضاف إليه صلاحيات واتساب |
| **منتج WhatsApp** | داخل التطبيق → Add Product → WhatsApp | يفتح واجهة Cloud API |
| **رقم هاتف مرسِل** | داخل منتج WhatsApp → API Setup | رقم منفصل عن رقمك الشخصي (رقم اختبار مجاني يكفي للبدء) |
| **معرّف رقم الهاتف** `WHATSAPP_PHONE_ID` | API Setup → Phone number ID | يرسل منه النظام الرسائل |
| **توكن دائم** `WHATSAPP_TOKEN` | Business Settings → System Users → Generate token | صلاحيات: `whatsapp_business_messaging` + `whatsapp_business_management` |

> **التوكن الدائم هو المفتاح:** توكن التطبيق المؤقت (24 ساعة) يكفي للتجربة،
> لكن سير العمل اليومي في GitHub يحتاج توكن System User دائمًا.

**التحقق من العمل التجاري (Business Verification):** مطلوب للوصول للإنتاج
الكامل (إرسال للجمهور وقوالب MARKETING). قالبا المنصة (**AUTHENTICATION** و
**UTILITY**) لا يتطلبان التحقق — يمكن البدء فورًا، والتحقق يرفع الحدود
(عدد الرسائل اليومي) ويُفعّل فئة التسويق لاحقًا.

---

## 1) ضبط الأسرار محليًا

في `.env` (غير ملتزم — موجود في .gitignore):

```bash
WHATSAPP_TOKEN=EAAG...   # توكن System User الدائم
WHATSAPP_PHONE_ID=123456789012345   # Phone number ID
# اختيارية — للأسف الافتراضيات سليمة:
# WHATSAPP_OTP_TEMPLATE=alforaij_otp
# WHATSAPP_ALERT_TEMPLATE=alforaij_alert
```

## 2) فحص الجاهزية

```bash
WHATSAPP_TOKEN=... WHATSAPP_PHONE_ID=... python scripts/whatsapp_setup.py --check
```

يطبع: الرقم المرسِل + الاسم الموثق + جودة المرسل + حساب الأعمال + حالة القالبين
(✅ معتمد / ⏳ قيد المراجعة / ❌ غير موجود) + الخطوات التالية. رمز الخروج 0 فقط
عندما يكون كل شيء معتمدًا.

## 3) إنشاء القالبين برمجيًا

```bash
python scripts/whatsapp_setup.py --create-otp      # قالب رمز التحقق
python scripts/whatsapp_setup.py --create-alert    # قالب تنبيه الفرصة
```

### قالب OTP (`alforaij_otp` — فئة AUTHENTICATION)
نصه **ثابت من Meta ولا يقبل التخصيص** — تُولّده Meta تلقائيًا بالعربية:
> «{{1}} هو رمز التحقق الخاص بك. لأمانك، لا تشارك هذا الرمز» + «ينتهي هذا الرمز
> خلال 10 دقائق» + زر «نسخ الرمز».

هذا يطابق تمامًا ما يرسله الخادم (`[code]` = متغير واحد). الاعتماد **فوري تقريبًا**
وقوالب التوثيق **مجانية** بلا رسوم محادثة. زر COPY_CODE (وليس ONE_TAP) لأنه لا
يتطلب تطبيقًا جوالًا — الموقع واجهة ويب.

### قالب التنبيه (`alforaij_alert` — فئة UTILITY)
النص المعتمد (3 متغيرات بالترتيب نفسه الذي يمرره `send_opportunity_alerts.py`):

```
فرصة جديدة من منصة الفريج العقاري
الرمز: {{1}}
المنطقة: {{2}}
السعر: {{3}} د.ك
افتح المنصة لعرض التفاصيل والمصادر
```

> **لماذا بلا رابط؟** قاعدة Meta الرسمية: **الروابط ممنوعة داخل متغيرات نصوص
> القوالب**. لهذا استُبعد الرابط عمدًا من القالب (رغم ذكره في خطة الحسابات
> الأصلية) — الرابط متاح داخل التطبيق في الجرس. الاعتماد: دقائق–ساعات
> (أسرع مع الحساب الموثق). فئة UTILITY تُحاسب برسوم محادثة حسب معدل الدولة
> في [قائمة أسعار Meta](https://developers.facebook.com/docs/whatsapp/pricing)
> — قوالب AUTHENTICATION مجانية دائمًا.

## 4) إثبات التسليم الفعلي

```bash
python scripts/whatsapp_setup.py --send-test +965XXXXXXXX
```

يرسل رمزًا تجريبيًا `123456` عبر قالب OTP إلى رقمك. إن وصل، فالتسليم يعمل من
البداية للنهاية: Supabase → السكربت → Cloud API → الهاتف.

## 5) رفع الأسرار إلى GitHub (لسير العمل اليومي)

```bash
gh secret set WHATSAPP_TOKEN
gh secret set WHATSAPP_PHONE_ID
gh secret set WHATSAPP_ALERT_TEMPLATE   # اختياري — الافتراضي alforaij_alert
```

`daily-data-update.yml` يقرأها تلقائيًا (الخطوة «Send opportunity alerts to
saved searches»). غيابها لا يكسر شيئًا: التنبيهات تتراكم في الجرس داخل التطبيق
والانحدار الأنيق يطبع تحذيرًا.

## 6) مشاكل شائعة وحلولها

| الخطأ | السبب | الحل |
| --- | --- | --- |
| `HTTP 401` عند `--check` | توكن منتهي/ناقص الصلاحية | توكن System User دائم بصلاحية `whatsapp_business_messaging` |
| `#131026 Message Undeliverable` | الرقم ليس على واتساب أو حظر القالب | جرّب رقمك الشخصي المسجّل فعلًا |
| `#131047 Re-engagement message` | رسالة نصية حرة خارج نافذة 24 ساعة | القنوات المجدولة تستخدم القوالب فقط |
| `#132000/#132001 parameter mismatch` | عدد المتغيرات لا يطابق القالب | أعد إنشاء القالب عبر `--create-otp`/`--create-alert` (يطابق الإرسال تلقائيًا) |
| `#131000/#131002 template not approved` | إرسال قبل الاعتماد | `--check` حتى يظهر ✅ معتمد |
| قالب UTILITY مرفوض | مخالفة محتوى (روابط/وعود) | أعد الإنشاء — النص أعلاه معتمد التصميم بلا روابط |

### قيود معلومة (بقصد)
- مسار الوكيل اليومي القديم (`backend/services/whatsapp_sender.py`) يرسل رسائل
  نصية حرة — يعمل فقط داخل نافذة محادثة 24 ساعة، وهو مسار تاريخي للعملاء
  المسجّلين. خط تنبيه الحسابات الجديد (القوالب) هو قناة الإنتاج المعتمدة.
- قالب OTP نصه إنجليزي-عربي تلقائي من Meta كما تنص الوثيقة (لا يمكن تخصيص
  صياغته) — الهدف الأمني (رمز 6 أرقام) يتحقق تمامًا.
