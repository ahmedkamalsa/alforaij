# سياق المشروع

الهدف الحالي هو منصة واحدة باسم `منصة الفريج للفرص والتقييم العقاري`، مدمجة بصريًا وتشغيليًا مع ستايل لوحة `alforaijboard`.

## الواجهة

- تعتمد نفس هوية لوحة الفريج الأساسية: رأس داكن بصورة الكويت، شعار الشركة، بطاقات أرقام، وفلاتر تشغيلية واضحة.
- الشاشة الرئيسية ليست صفحة شرح؛ هي مركز عمل مباشر للبحث، التقييم، الفرص، المصادر، والأدلة.
- أي قسم يدوي زائد يجب أن يكون داخل تفاصيل متقدمة فقط إذا كان بديلًا احتياطيًا، وليس المسار الأساسي.

## التشغيل الآلي

- وكيل التحديث اليومي هو المسار الأساسي لتحديث المصادر والفرص.
- موعد التشغيل المستهدف: 6:00 صباحًا يوميًا.
- الكاش المقترح: يومي للفرص والنتائج التشغيلية، وأسبوعي للموجزات والتقارير الثقيلة.
- استيراد صفقات وزارة العدل من الواجهة بديل احتياطي فقط عند توفر CSV/JSON موثق؛ المسار الأساسي هو `OFFICIAL_TRANSACTIONS_SOURCE`.

## مصادر التقييم

- الفريج هو خط الأساس المحلي.
- المصادر الخارجية تدخل فقط إذا أعادت إعلانًا منظمًا قابلًا للتدقيق: منطقة، نوع عقار، عملية، سعر/مساحة عند الحاجة، ورابط.
- الصفقات الرسمية هي أعلى مصدر للتقييم عند حفظها في `official_transactions`.
- مؤشرات البنوك/PACI/كويت فايندر/تقارير السوق لا يتم ادعاء اعتمادها إلا بعد وجود بيانات منظمة أو رابط/ملف موثق داخل التقرير.

## سياسة العرض

- لا تعرض رقمًا بلا سبب ومصدر.
- لا تعرض مصدرًا وكأنه دخل التقييم إذا كان مجرد رابط مراجعة.
- لا تخلط مساحة العقار مع الارتداد أو الواجهة أو عرض الشارع.
- أولوية العرض: خلاصة القرار، فرص المكسب، الإعلانات المشابهة، النتائج المرتبة، ثم تفاصيل المصادر والأدلة.
