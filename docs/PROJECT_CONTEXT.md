# سياق المشروع

الهدف هو إنشاء مساعد محلي مستقل باسم `مساعد الفريج للبحث والتقييم العقاري`.

المساعد ليس بديلًا عن لوحة الموظفين، وليس CRM. دوره:

- فهم طلب عقاري عربي.
- تحويله إلى فلاتر قابلة للتعديل.
- البحث داخل بيانات الفريج.
- تقييم السعر استرشاديًا حسب المقارنات المتاحة.
- توضيح سبب ترتيب النتائج والثقة والقيود.

المشروع الأصلي `alforaijboard` يستخدم للقراءة فقط. أي تعديل أو نشر للوحة الحالية ليس جزءًا من هذا التطبيق.
