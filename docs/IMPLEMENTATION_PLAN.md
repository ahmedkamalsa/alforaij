# خطة التنفيذ

## المرحلة الحالية

- تطبيق محلي مستقل يعمل بدون حزم خارجية.
- واجهة RTL لتحليل الطلب وتشغيل البحث والتقييم.
- استيراد بيانات الفريج من payload الموجود في لوحة البيانات.
- اختبارات تمنع اعتبار الارتداد أو الواجهة أو عرض الشارع مساحة للعقار.

## المراحل التالية

1. ربط صفقات رسمية أو ملفات صفقات موثوقة.
2. تحسين كشف التكرار باستخدام تشابه نصي أقوى ومصادر متعددة.
3. إضافة Supabase لحفظ التقارير والنتائج.
4. إضافة موصلات خارجية بعد الموافقة على مصادرها وشروطها.
5. إضافة تقييم دخل للعقارات الاستثمارية عندما تتوفر بيانات دخل وصفقات كافية.
