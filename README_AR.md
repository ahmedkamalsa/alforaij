# منصة الفريج للبحث والتقييم العقاري — الشرح الكامل والشامل

منصة عربية متكاملة لتحليل السوق العقاري في دولة الكويت: تبحث في بيانات الفريج والمصادر الخارجية، تقارن الأسعار، تعرض الأدلة والمصادر، وتحفظ مسار القرار والوكلاء المساعدين في Supabase. الهدف ليس مجرد عرض إعلانات عقارية، بل مساعدة المستثمر والمستخدم العربي على فهم السعر العادل، الفرصة الحقيقية، ومستوى الطلب الفعلي حول كل عقار.

---

## 🎯 فكرة العمل ورؤية المنصة

```text
نص المستخدم (سؤال / وصف طلب)
  ├── 1. تحليل النية والمنطقة والميزانية (Intent Agent)
  ├── 2. جلب بيانات الفريج والمصادر الخارجية (Source Agent)
  ├── 3. تصفية التكرار وتصنيف الإعلانات (Quality & Classification)
  ├── 4. تقييم السعر والفرصة من الأرقام الفعلية (Valuation Agent - حسابي حتمي)
  ├── 5. ربط التحليل بالطلب الحقيقي والعملاء (Demand Agent)
  ├── 6. صياغة التقرير العربي والأدلة الموثقة (Report Agent)
  └── 7. حفظ التقرير ومسار الوكلاء في Supabase
```

> ⚠️ **ملاحظة هامة:** النماذج اللغوية والذكاء الاصطناعي لا تنتج أرقام التقييم إطلاقًا. الأرقام تأتي من المعادلات الرياضية الحتمية والمقارنات الموثقة ببيانات الفريج والمصادر الرسمية، بينما يُستخدم الذكاء الاصطناعي لتفسير النتائج، تلخيص الأدلة، واكتشاف نواقص البيانات.

## 🚀 التشغيل السريع محليًا

### المتطلبات الأساسية
- **Python 3.11** أو أحدث.
- **Node.js 20+** (اختياري، لفحوصات Playwright والواجهة).
- **Supabase** (اختياري؛ عند غياب المفاتيح تعمل المنصة محليًا ببيانات الفريج المخزنة).

### خطوات التشغيل
1. افتح موجه الأوامر في مجلد المشروع:
   ```bash
   cd alforaij-research-assistant
   ```
2. شغّل الخادم المحلي:
   ```bash
   PYTHONIOENCODING=utf-8 python -m backend.main
   ```
3. افتح المتصفح على العنوان:
   ```text
   http://127.0.0.1:8000
   ```
4. للتحقق من صحة الخادم:
   ```bash
   curl http://127.0.0.1:8000/api/health
   ```

## 🤖 مسار الوكلاء الأذكياء (`agentTrace`)

كل عملية تحليل تنتج سجلًا شفافًا ومستقلًا للوكلاء الأذكياء يظهر في الواجهة تحت "مسار التحليل":

1. **`intent_agent`**: يفهم نص المستخدم ويستخرج المنطقة، نوع العقار، والحد الأقصى للسعر.
2. **`source_agent`**: يحدد المصادر الخارجية والداخلية المشاركة وحالة كل مصدر.
3. **`quality_agent`**: يقيم جودة البيانات ونواقصها ويرصد أية إعلانات مكررة.
4. **`valuation_agent`**: يحسب متوسط سعر المتر، الوسيط، ودرجة التوصية الاستثمارية.
5. **`demand_agent`**: يربط التحليل بما يطلبه المشترون والمستأجرون الفعليون.
6. **`report_agent`**: يصيغ التقرير النهائي باللغة العربية مع توثيق المصادر بالأدلة.

## 🔌 مزودات الذكاء الاصطناعي (AI Providers)

تعتمد المنصة نظام السقوط التلقائي (Fallback System) بين عدة مزودات للذكاء الاصطناعي:

```text
NVIDIA NIM (MiniMax M3) ➔ FreeLLMAPI ➔ Google Gemini ➔ OpenRouter ➔ Ollama المحلي ➔ AgentRouter
```

إذا تعطلت جميع المزودات الخارجية، تتحول المنصة تلقائيًا إلى **التقييم المحلي الحتمي** دون أن يظهر خطأ للمستخدم.

## 🌐 النشر المباشر و GitHub Pages

- **الرابط المنشور المباشر للموقع/اللوحة:** [https://ahmedkamalsa.github.io/alforaijboard/](https://ahmedkamalsa.github.io/alforaijboard/)

### مسار النشر الآلي:
تم إعداد وتفعيل workflows النشر في `.github/workflows/`:
1. **`deploy-alforaijboard.yml`**: يقوم بنشر الواجهة الاسترشادية مباشرة إلى فرع `gh-pages` لـ `alforaijboard`.
2. **`deploy-github-pages.yml`**: ينشر أحدث نسخة من `frontend/` تلقائيًا على GitHub Pages عند كل الرفع (`push`) إلى الفرع الرئيسي `main`.

يمكن ضبط رابط الـ Backend الحي في متغيرات GitHub Actions:
```env
ALFORAIJ_API_BASE=https://your-backend-api.example.com
```

## 🧪 التحقق والاختبارات الشاملة

قبل رفع أي تعديل، يتم تنفيذ الفحوصات التالية لضمان خلو النظام من الأخطاء:

1. **اختبارات الوحدة (Pytest):**
   ```bash
   python -m pytest tests/ -q
   ```
   *(تحتوي المجموعات على أكثر من 680 اختبارًا تغطي كامل وظائف الـ Backend والمستوردين)*.

2. **فحص الأداء والسرعة (Playwright Performance Audit):**
   ```bash
   python scripts/run_performance_checks.py
   ```
   *(يفحص سرعة فتح كل التبويبات بالتحميل البارد والدافئ ومعدل استجابة الكاش ومطابقة الحدود الزمنية)*.

3. **فحص سلامة ملفات JavaScript:**
   ```bash
   node --check frontend/app.js
   node --check frontend/sw.js
   ```
